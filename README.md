# ER Schema Tool

## 📌 Overview
The ER Schema Tool is a database design tool that helps users create and visualize Entity-Relationship (ER) diagrams. It simplifies database planning by representing entities, attributes, keys, and relationships in a clear and structured format.

## ✨ Features
- Create and visualize ER diagrams.
- Define entities and their attributes.
- Identify primary keys and foreign keys.
- Represent relationships between entities.
- Simplify database schema design and planning.

## 🎯 Objective
To make database design easier, more interactive, and understandable by providing a visual representation of database structures before implementation.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start creating and visualizing your ER diagrams.

## 💡 Use Cases
- Database management system (DBMS) projects.
- Academic database design assignments.
- Visualizing relationships between database tables.
- Planning database schemas before SQL implementation.

## 👨‍💻 Conclusion
The ER Schema Tool provides a simple and intuitive way to design and understand database schemas, helping users organize data and relationships efficiently.
